# إعداد GitHub MCP في VS Code / Cursor

هذا الملف يشرح إعداد التكامل يدويًا؛ لا يمكن تثبيت الإضافة أو تسجيل الدخول إلى حساب GitHub من داخل ملفات المشروع نفسها.

## الخطوات

1. افتح المشروع `food-demand-analysis` في VS Code.
2. افتح **Extensions** من الشريط الجانبي.
3. ابحث عن `@github mcp` كما هو مطلوب في تعليمات المشروع.
4. إذا ظهرت إضافة GitHub MCP المناسبة والمتاحة في بيئتك، افتحها ثم اختر **Install**.
5. أكمل تسجيل الدخول أو التفويض الذي تعرضه VS Code، وتأكد من أنك تمنح الصلاحيات التي تحتاجها فقط.
6. افتح نافذة Copilot Chat أو أداة الدردشة التي تدعم MCP في إعدادك، وتحقق من أن خادم GitHub متصل قبل طلب إنشاء Issues.
7. لا تضع Personal Access Token أو أي مفتاح سري في `README.md` أو ملفات المشروع أو المحادثات العامة.

## مطالبة جاهزة لإنشاء Issues

بعد الاتصال، أرسل إلى Copilot المطالبة التالية وعدّل اسم المستودع إذا لزم:

> راجع `README.md` و`AGENTS.md` وملفات المشروع في مستودع `food-demand-analysis`. أنشئ GitHub Issue منفصلًا لكل مهمة متبقية فقط، مع عنوان واضح ووصف ومعايير قبول وقائمة تحقق. لا تنشئ Issues مكررة، ولا تغلق أي Issue إلا بعد تنفيذ المهمة والتحقق من نتيجتها. قبل أي تعديل أو إغلاق، اعرض ملخصًا بما ستفعله وانتظر موافقتي إذا كانت صلاحياتك تتطلب ذلك.

## مهام مقترحة لتتبعها

- [ ] مراجعة جودة البيانات وتوثيق قرارات التنظيف.
- [ ] مراجعة التحليلات الإحصائية وتجنب الاستنتاجات السببية.
- [ ] مراجعة تقييم التنبؤ ومقارنة MAE بخط الأساس.
- [ ] مراجعة التقرير والعرض التقديمي قبل التسليم.
- [ ] التحقق من أن ملفات البيانات الخام غير مضافة إلى Git إذا كان المستودع عامًا.

## ملاحظة

أسماء الإضافات وواجهات الإعداد قد تختلف حسب إصدار VS Code/Cursor وحساب GitHub وسياسات المؤسسة. إذا لم تظهر نتيجة مناسبة عند البحث، لا تثبّت إضافة غير موثوقة لمجرد تشابه الاسم؛ ارجع إلى تعليمات المقرر أو وثائق GitHub الرسمية.
